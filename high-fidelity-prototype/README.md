## Title 
>High Fidelity Prototype Documentation

## Description
>The High Fidelity Prototype is meant to be a static assortment of html pages to best represent what the finished app will be. Any user can open the html pages within their system as long as they're in the same folders they are now by opening VSCode and using the preview tool. A dummy provider and customer account is included in the prototype alongside highly detailed listings. The prototype is not meant to be functional and won't actually write any new data- it's just meant to show how the app will be used.
